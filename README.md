## Descrição
Este repositório contém uma série de 25 exercícios práticos desenvolvidos na linguagem Python para a disciplina de Programação de Aplicativos. O objetivo do projeto é demonstrar e praticar conceitos essenciais de lógica de programação, incluindo manipulação de variáveis, estruturas condicionais, laços de repetição e listas. 

## Tecnologia Utilizada
* **Linguagem:** Python
* **Versão:** 3.14

## Como Executar
Para rodar qualquer um dos exercícios contidos neste repositório de forma independente, siga as instruções abaixo:

1. Certifique-se de ter o editor de código **Visual Studio Code (VS Code)** instalado em seu computador.
2. Instale a extensão oficial do **Python** no VS Code.
3. Abra o terminal do seu sistema operacional e clone o repositório utilizando o comando:
   `git clone https://github.com/victorlaureano-art/exercicios-python.git`
4. Abra a pasta clonada no VS Code.
5. Selecione o arquivo desejado na lista e execute o código utilizando o botão de "Run" (Executar) da extensão ou digitando o comando `python nome_do_arquivo.py` no terminal do próprio editor.
